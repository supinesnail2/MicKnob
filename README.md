# MicKnob

Simple Windows controls for your speakers, your microphone and how your voice sounds.

## Download

Get `MicKnob.exe` from the [Releases page](../../releases/latest) and double-click it. Windows may show an "unknown publisher" warning because the app isn't code-signed.

Mic boost and voice effects need [Equalizer APO](https://sourceforge.net/projects/equalizerapo/) installed.

## Build from source

Run `build.bat`. It uses the C# compiler included with Windows.
